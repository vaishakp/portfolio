Research codes I have written. Codes with a public release are linked.

- **tdanalysis** — An accelerated, GPU-enabled exact time-domain inference engine for gravitational wave astronomy, using the Gohberg–Semencul representation of Toeplitz inverses. [PyPI](https://pypi.org/project/tdanalysis/)
- **nrhjsurrogate** — A GPU-native numerical relativity surrogate waveform family providing analytic derivatives and error estimates. [PyPI](https://pypi.org/project/nrhjsurrogate/) · [documentation](https://psu-edu.github.io/nrhjsurrogate/)
- **spectral/spectools** — A collection of spectral transforms and helpers with built-in error monitoring. [PyPI](https://pypi.org/project/spectools/) · [GitHub](https://github.com/vaishakp/spectral) · [documentation](https://spectools.readthedocs.io/en/latest/)
- **paralleltemplatebank** — A massively parallel reduced-spin template bank generator for precessing compact binaries with higher modes.
- **purohit** — A library to semi-automate gravitational wave parameter estimation.
- **popsampler** — A sampler for drawing events from GWTC population models. [GitHub](https://github.com/vaishakp/popsampler)
- **sxstools** — Tools for handling SXS numerical relativity catalogue data.
- **gwdetectors** — A library of gravitational wave detector models and sensitivity curves.
- **waveformtools** — A library of data handling functions for the Einstein Toolkit and SpEC. [PyPI](https://pypi.org/project/waveformtools/) · [GitHub](https://github.com/vaishakp/waveformtools)
- **qlmtools** — A library of functions for analysis and handling of 2D dynamical horizon numerical data.
- **quasinormal** — A library of functions for analysis of quasi-normal modes.
- **wfs_match** — An MPI-based parallel template parameter estimation routine.
- **yumcee** — An MPI-based Markov chain and nested Monte Carlo sampler.
- **null_solver** — An implementation of the dual-null characteristic numerical solver for scattering problems.
- **pkginstaller** — A simple package installer for HPCs. [GitLab](https://gitlab.com/vaishakp/pkginstaller)
- **nrcatalogtools** — A unified interface to numerical relativity waveform catalogs. Contributor.
